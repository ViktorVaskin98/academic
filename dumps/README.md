# Дампы блоков — свободное припоминание

Один файл на дамп: `dump01_dl_base.md`, `dump02_cv_emb.md` и так далее.

**Когда:** утром следующего дня после блока, холодно, до любого разбора. **Сколько:** 15 минут.
Пишешь свободным текстом всё, что помнишь по блоку, каждый пункт — с меткой уверенности:

| Метка | Значение |
|---|---|
| `(!)` | уверен, готов защищать под давлением |
| `(?)` | помню суть, поплыву на деталях |
| `(??)` | знаю, что тема есть, содержания нет |

Разбор — по чек-листу выходов в конце файла блока.

Структура файла:

```
# Дамп: <блок> — <дата>

## Покрытие: X / Y пунктов чек-листа
## Калибровка: N сбоев

## Твой текст
<как написал, дословно, без правок>

## Разбор
| # | Пункт | Твоя метка | Оценка | Комментарий |
✅ верно · ⚠️ неточно · ❌ неверно · ⬜ не сказал · 🎯 сбой калибровки

## Не сказано вообще
## В redo-list
```

🎯 сбой калибровки — `(!)` и неверно (хуже всего: на собесе это уверенная ошибка) или `(??)` и верно.
