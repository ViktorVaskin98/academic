# Список пересдач (spaced repetition)

Правила — см. [`PLAN.md`](PLAN.md), раздел "Режим надрочить".
Формат строки: `- [ ] LC### Название — добавлено ГГГГ-ММ-ДД — пересдача 1: ___ — пересдача 2: ___`

Задача убирается из списка только после 2 холодных пересдач подряд без сбоев.
