**Источник:** `data/Все алгозадачи с Яндексa.pdf` — компиляция от телеграм-канала «Поступашки • Карьера» (@postypashki_old). Это не внутренний документ Яндекса, а учебный лид-магнит их платных курсов, но с признаками реальной фактуры: внутренняя терминология («АА-секция»), система штрафных баллов, формулировки со стороны интервьюера. ~30 из 39 задач имеют точный или близкий аналог на LeetCode — то есть материал стандартный, просто отобранный под компанию.

**Сквозные требования, которые видны почти в каждой задаче:**
- Явное O(1) дополнительной памяти
- «Напиши руками, а не через стандартную библиотеку»
- Один проход по данным там, где это возможно
- Аккуратность на краевых случаях (пустой вход, один элемент, все элементы одинаковые) — за это штрафуют

**Что из этого следует для плана:** вес строк поднят с «побочно» до двух полноценных блоков (недели 4 и 6), добавлен блок проектирования структур (неделя 7), DP и графы урезаны до минимального пола.

- [ ] **С-4. Порядок слов наоборот без изменения позиций пробелов** — `"hello_my__dear_world__"` → `"_world_dear___my_hello_"`. ~LC151/186 + авторское усложнение 🖊 → **неделя 6**
- [ ] **С-5. Восстановить все IP-адреса из строки цифр** — backtracking, ловушки: ведущие нули, октет > 255. LC93 → **неделя 6**

- [ ] **С-10. OneEditApart** — можно ли получить одну строку из другой за ≤1 правку. O(n)/O(1), не дублировать логику веток. LC161 → **неделя 6**

- [ ] **С-12. Нормализация пробелов** — схлопнуть подряд идущие пробелы, in-place, O(1) памяти 🖊 → **неделя 6**
- [ ] **С-13. fuzzysearch** — является ли строка подпоследовательностью другой, один проход, без regexp. LC392 → **неделя 6**
