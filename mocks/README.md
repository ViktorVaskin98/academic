# Протоколы мок-собесов

Один файл на мок: `mock01.md` (пн 28.09).

**Формат мока — как реальная ML-секция Авито, 60 мин:**
~25 мин классический ML (метрики обязательно) → ~10 мин база DL / CV → ~25 мин NLP (трансформер, BERT, один кейс).
Вопросы в стиле слива, follow-up до упора. Формулы — тем способом, которым будешь писать на собесе
(см. [`../tickets/00_meta.md`](../tickets/00_meta.md), раздел 2).

Структура протокола:

```
# МОК №N — дата, длительность

## Итоговая оценка: X/10
Вердикт одной строкой: прошёл бы / на грани / провал.

## По темам
| Тема | Оценка | Комментарий |

## Разбор по вопросам
### В1. <вопрос>
**Ответ:** <что сказал>
**Оценка:** ✅ / ⚠️ / ❌
**Что не так:** <разбор>
**Эталон:** <как надо было>

## Что уходит в redo-list
## Что делать до следующего мока / собеса
```
