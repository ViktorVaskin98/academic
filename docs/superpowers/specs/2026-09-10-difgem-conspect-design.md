# Интерактивный конспект по дифференциальной геометрии — дизайн

Дата: 2026-09-10
Курс: «Дифференциальная геометрия», ИТМО, направление «Инженерия ИИ», 2 курс
Ветка: `difgem`

## Проблема

Преподаватель выдаёт конспекты-скелеты: строгие `Def`/`Lm`/`Ex`/`NB` без интуиции,
без картинок, без разбора доказательств. Практические листы содержат задачи, часть
из которых сформулирована в терминах ML (классификаторы, вероятностные симплексы,
разбиение объектов на неразличимые блоки), но связь не проговаривается.

Нужен продукт: локальный HTML-сайт, где формальный скелет курса сохранён 1:1, а
поверх него лежат слои интуиции, примеров, контрпримеров, интерактивных визуализаций
и связей с ИИ. Плюс инструменты подготовки к экзамену.

## Границы

В скоупе:
- Сайт-конспект по лекциям курса (входные данные — PDF преподавателя).
- Разборы практических листов.
- Интерактивные визуализации и Manim-анимации.
- Шпаргалка и карточки самопроверки.
- Шаблон + скилл, чтобы каждая следующая лекция делалась по одному шаблону.

Вне скоупа:
- Автоматический парсинг PDF в HTML. Содержание переносится осмысленно, вручную.
- Любой бэкенд, база, аккаунты. Сайт — статические файлы.
- Другие предметы. Структура допускает их добавление, но не проектируется под них.

## Решения, принятые на этапе брейншторма

| Вопрос | Решение |
|---|---|
| Организация файлов | `index.html` (карта курса) + файл на лекцию, общие `assets/` |
| Стиль текста | Скелет преподавателя дословно, с его нумерацией; слои сверху |
| Визуал | SVG-фигуры как база + 3–6 интерактивных виджетов на лекцию |
| Практика | Три свёрнутых уровня: подсказка → идея → полное решение |
| Математика | KaTeX, вендоренный локально — работает офлайн |
| Тема | Тёмная техничная, светлая и печатная в комплекте |
| Фичи | Связь с ML, шпаргалка, карточки, встроенные видео |
| Анимации | Гибрид: интерактив в браузере + Manim для 1–2 «вау»-сцен на лекцию |
| Главная | Карта курса + глобальный поиск по всем анкорам курса |
| Процесс | Лекция 1 как эталон + скилл `difgem-notes` для следующих |
| Скоуп №1 | Каркас + лекция 1 целиком. Практика №1 — отдельной итерацией |

## Структура файлов

Корень сайта — `conspect/` (папка уже создана пользователем). Входные материалы
остаются в `data/` и не модифицируются.

```
academic/
├── conspect/
│   ├── index.html              карта курса + глобальный индекс/поиск
│   ├── cheatsheet.html         автосборная шпаргалка
│   ├── lectures/
│   │   └── lecture-01.html
│   ├── pract/
│   │   └── pract-01.html       (итерация 2)
│   ├── assets/
│   │   ├── style.css           темы: dark / light / print
│   │   ├── app.js              навигация, прогресс, поиск, карточки, тема
│   │   ├── viz.js              библиотека виджетов
│   │   ├── search-index.json   генерируется tools/build-index.mjs
│   │   └── vendor/katex/       офлайн KaTeX
│   ├── media/
│   │   ├── video/              mp4 (копии из exemp/)
│   │   └── manim/              рендеры Manim-сцен
│   ├── manim/scenes/           исходники .py
│   └── tools/build-index.mjs   пересборка search-index.json
├── data/                       PDF преподавателя, read-only
├── exemp/                      исходные видео
└── .claude/skills/difgem-notes/SKILL.md
```

Сайт открывается двойным кликом по `conspect/index.html`. Ни сборки, ни сервера,
ни интернета не требуется.

## Компоненты

### `assets/style.css`

Дизайн-система: CSS-переменные для палитры, типографики, отступов. Три темы через
`:root` + `[data-theme="light"]` + `@media print`. Классы блоков (`.block--def`,
`.block--lemma`, ...) отличаются только акцентным цветом и иконкой — добавление
нового типа блока не требует новой вёрстки.

### `assets/app.js`

Независимые модули, каждый инициализируется по наличию своего DOM-хука:
- `theme` — переключатель темы, запоминание в `localStorage`.
- `toc` — построение бокового оглавления из заголовков страницы + подсветка активного.
- `progress` — отметки «разобрано» на уровне разделов, `localStorage`, агрегация на главной.
- `search` — живой поиск по `search-index.json` с переходом на анкор.
- `reveal` — свёрнутые блоки (доказательства, уровни подсказок).
- `flashcards` — карточки и мини-квизы с проверкой ответа.

### `assets/viz.js`

Библиотека виджетов. Контракт: каждый виджет — класс с конструктором
`(container: HTMLElement, config: object)`, монтируется в `<div data-viz="name">`
с параметрами в `data-*`. Никакой связи с конкретной лекцией — конфигурация приходит
из HTML. Виджет обязан работать без интернета и корректно вести себя на телефоне.

Виджеты для лекции 1:
1. `PointProber` — таскаемая точка на множестве в ℝ², индикатор
   внутренняя/граничная/внешняя + рисуемая окрестность. Покрывает Def. 6, 8, 9, Lm. 4.
2. `SetInspector` — множество на прямой (`[2,5) ∪ {7}`), кнопки `Int`/`Cl`/`∂`,
   переключатель топологии (стандартная / стрелка / конечных дополнений).
   Покрывает Ex. 8–11, задачи 3, 9, 10.
3. `AxiomChecker` — конструктор объединений и пересечений, детектор нарушений.
   Ключевая сцена: `⋂ₙ (−1/n, 1/n) = {0}` не открыто, отсюда «конечного числа» в аксиоме 3.
4. `SubspaceViz` — NB 1: `U = (−1,1)×{0}` открыто в `S = ℝ×{0}`, не открыто в ℝ².
   Переключатель окружающего пространства.
5. `TopologyLattice` — все топологии на `{a,b}` и `{a,b,c}`, порядок «сильнее/слабее».
   Покрывает Def. 4, NB 2, задачи 1 и 18c.
6. `ArrowTopology` — `[0,+∞)` с топологией стрелки, интерактивные `Int`/`Cl`.
   Покрывает Ex. 4, 6, 10, задачи 9b, 17*.

### `assets/vendor/katex/`

KaTeX + шрифты, скачанные один раз и закоммиченные. Автоматический рендер
`$...$` и `$$...$$` после загрузки страницы.

### `tools/build-index.mjs`

Node-скрипт без зависимостей. Сканирует `lectures/*.html` и `pract/*.html`, собирает
из блоков их `id`, тип, заголовок, краткий текст и родительский раздел, пишет
`assets/search-index.json`. Запускается вручную после правки лекции. Наличие
скрипта — причина, по которой добавление лекции не требует ручной правки главной
страницы и шпаргалки.

### `manim/scenes/`

Сцены на ManimCE, рендеры кладутся в `media/manim/` как mp4 и коммитятся.
Для лекции 1 две сцены:
- `FiniteIntersection` — интервалы `(−1/n, 1/n)` схлопываются в точку; открытость
  теряется. Объясняет, почему в аксиоме 3 пересечение конечное.
- `BoundaryOfRationals` — `Int(ℚ) = Int(ℚᶜ) = ∅`, `∂ℚ = ℝ`. Самый
  неинтуитивный момент лекции (Ex. 9).

Риск: на Windows у ManimCE иногда конфликтуют Cairo/Pango и требуется ffmpeg.
Митигация: Manim изолирован в отдельном подпроекте, его отсутствие не ломает сайт —
на месте видео показывается статический SVG-фолбэк с той же идеей.

### Видео

`Рогатая_сфера_Александера.mp4` и `Развязывание_узла_в_4D.mp4` (1.3 МБ суммарно)
копируются в `conspect/media/video/`. Размещение: блок «куда мы идём» на главной
как мотивация, плюс ссылка из раздела про замыкание — как демонстрация того, что
наивная интуиция про «границу» и «вложение» ломается.

## Анатомия страницы лекции

Двухколоночная: липкое оглавление слева, контент справа. Контент — последовательность
блоков, каждый с собственным анкором вида `#def-7`, `#lm-4`, `#ex-8`.

| Тип блока | Содержание | Источник |
|---|---|---|
| `def` / `lemma` / `theorem` / `example` / `nb` | Дословная формулировка с нумерацией преподавателя | PDF |
| `intuition` | Что утверждение значит по-человечески | автор конспекта |
| `viz` | SVG-фигура или интерактивный виджет | автор конспекта |
| `proof` | Свёрнуто; разбор по шагам с пояснением каждого перехода | PDF + расширение |
| `counter` | Контрпример | автор конспекта |
| `trap` | Типичная ошибка именно в этом месте | автор конспекта |
| `ml` | Связь с ML/ИИ | автор конспекта |
| `card` | Карточка самопроверки: формулировка скрыта | автор конспекта |

Нумерация и обозначения совпадают с PDF преподавателя дословно (`Int_X(S)`, `Cl_X(S)`,
`∂S`, `τ_st`, `τ_→`, `τ_CF`, `τ_d`, `τ_a`). Расхождение обозначений с экзаменом
считается дефектом.

## Связь с ИИ: конкретные привязки для лекции 1

Не абстрактное «топология полезна», а точные соответствия, взятые из практического листа:
- `Int_X(A) ∪ Int_X(X\A)` — множество точек, где решение классификатора локально
  устойчиво; `∂A` — где оно неустойчиво (задача 7).
- Вероятностный симплекс `Δ = {p : pᵢ ≥ 0, Σpᵢ = 1}` — выход softmax; его внутренность
  и граница различаются в зависимости от того, берём ли мы `ℝ³` или гиперплоскость `H`
  (задача 11).
- Топология из объединений блоков неразличимых объектов — что значит «признаки не
  различают объекты»; уточнение признаков делает топологию сильнее (задача 12).
- Шары `B₂` и `B∞` задают одну топологию — почему выбор нормы не меняет понятие
  «близко», но меняет геометрию (задача 8).

## Как добавляется следующая лекция

1. PDF кладётся в `data/lections/`.
2. `conspect/lectures/lecture-NN.html` создаётся из шаблона.
3. Содержание переносится блоками, добавляются слои.
4. Нужные виджеты берутся из `viz.js`; новые добавляются туда же по тому же контракту.
5. `node tools/build-index.mjs` — главная, поиск и шпаргалка обновляются сами.

Правила этого процесса (структура, нотация, типы блоков, каталог виджетов, стиль
объяснений) фиксируются в `.claude/skills/difgem-notes/SKILL.md`, чтобы следующие
лекции не требовали пересогласования стиля.

## Критерии готовности итерации 1

- `conspect/index.html` открывается двойным кликом, работает без интернета.
- Формулы отрендерены KaTeX, а не показаны сырым LaTeX.
- Лекция 1 содержит все 12 `Def`, 5 `Lm`, 11 `Ex`, 6 `NB` с сохранённой нумерацией.
- Каждый раздел лекции 1 имеет хотя бы один визуал.
- Шесть виджетов работают: мышь, тач, ресайз окна.
- Доказательства `Lm. 3` и `Lm. 5` разобраны по шагам.
- Поиск с главной находит `Int`, `стрелка`, `замыкание` и ведёт на нужный анкор.
- Обе Manim-сцены отрендерены и встроены, либо на их месте стоит SVG-фолбэк.
- Тёмная и светлая темы читаемы, печать не ломается.
- Прогресс переживает перезагрузку страницы.
