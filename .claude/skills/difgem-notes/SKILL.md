# Конспект по дифгему

Сайт-конспект курса «Дифференциальная геометрия» (ИТМО, Инженерия ИИ). Задача скилла —
чтобы каждая новая лекция получалась в том же стиле, что эталонная `lecture-01.html`,
без пересогласования решений.

## Что где лежит

```
conspect/
├── index.html              карта курса; новые лекции добавляются карточкой сюда
├── cheatsheet.html         генерируется, править не нужно
├── lectures/lecture-NN.html
├── pract/pract-NN.html
├── assets/
│   ├── topology.js         множества на прямой, Int/Cl/граница в τ_st, τ_→, τ_CF
│   ├── finite-topology.js  топологии на конечном множестве
│   ├── render.js           примитивы отрисовки SVG
│   ├── viz.js              реестр и реализации виджетов
│   ├── app.js              тема, оглавление, прогресс, поиск, карточки
│   ├── style.css           дизайн-система
│   └── bundle.js           СОБИРАЕТСЯ, править запрещено
├── tools/build.mjs         сборка bundle.js + поискового индекса + данных шпаргалки
├── tools/serve.mjs         локальный сервер для проверки
├── tests/*.test.mjs        юнит-тесты чистых модулей
└── manim/scenes/           исходники анимаций
```

Исходники преподавателя — в `data/lections/` и `data/pract/`, они read-only.

## Три команды

```bash
npm test          # 41+ тестов, должны проходить все
npm run build     # пересобрать bundle.js, search-index.js, cheatsheet-data.js
npm run serve     # http://localhost:4173 для проверки в браузере
```

Страницы подключают **`assets/bundle.js`**, а не ES-модули: по `file://` браузер блокирует
`import` из-за CORS, а конспект обязан открываться двойным кликом. Поэтому после любой правки
файлов в `assets/*.js` обязателен `npm run build`.

## Железные правила

1. **Нотация 1:1 с преподавателем.** `Int_X(S)`, `Cl_X(S)`, `∂S`, `τ_st`, `τ_→`, `τ_CF`,
   `τ_d`, `τ_a`, `O_P`, `⟨X, τ⟩`, `S^c = X\S`. Нумерация блоков — как в PDF: `Def. 7` в конспекте
   обязан быть `Def. 7` в PDF. Расхождение с экзаменом считается дефектом.
2. **Формулировки из PDF переносятся дословно.** Всё добавленное идёт отдельными блоками,
   чтобы студент видел, где кончается препод и начинается пояснение.
3. **Никакой математики в коде виджетов.** Любое новое вычисление идёт в `topology.js`
   или `finite-topology.js` вместе с тестом. Виджет только рисует.
4. **Каждый раздел получает минимум один визуал** и минимум один блок `ml`.
5. **Ответы проверяются программно, где это возможно.** Прежде чем написать
   «$\mathrm{Int}(S) = (2,5)$», посчитай это модулем и сверься.
6. **Никаких внешних ссылок на ресурсы.** Ни CDN, ни шрифтов из сети. Проверка:
   `grep -rn "https\?://" conspect --include=*.html --include=*.js --include=*.css | grep -v vendor`
   должен быть пуст.

## Типы блоков

Разметка блока: `<div class="block block--KIND" id="ID" data-label="МЕТКА" data-title="НАЗВАНИЕ">`
с первой строкой `<div class="block__label">МЕТКА <span class="block__title">НАЗВАНИЕ</span></div>`.
`id` обязателен для всего, что должно попадать в поиск.

| KIND | Метка | Назначение | id |
|---|---|---|---|
| `def` | `Def. N` | определение из PDF | `def-N` |
| `lemma` | `Lm. N` | лемма из PDF | `lm-N` |
| `theorem` | `Th. N` | теорема из PDF | `th-N` |
| `example` | `Ex. N` | пример из PDF | `ex-N` |
| `nb` | `NB N` | замечание из PDF | `nb-N` |
| `intuition` | `Интуиция` | что утверждение значит по-человечески | не нужен |
| `trap` | `Ловушка` | где именно тут ошибаются | не нужен |
| `counter` | `Контрпример` | где ломается интуиция | не нужен |
| `ml` | `ИИ` | связь с машинным обучением | `ml-<тема>` |
| `summary` | `Сводка` | таблица, которой нет в PDF | не нужен |
| `card` | `Карточка` | самопроверка, в поиск не попадает | `card-<тема>` |

Доказательства — не блок, а `<details class="reveal reveal--proof">` с шагами
`<div class="proof-step">` из трёх частей: номер, шаг, и `proof-step__why` с указанием
использованной аксиомы или определения. Каждый шаг обязан отвечать «почему можно так».

Раздел оформляется как `<section id="s-N-M" data-section-id="lecture-NN/N.M">` — второй
атрибут включает отметку «разобрано» и подсчёт прогресса на главной.

## Каталог виджетов

Монтирование: `<div data-viz="ИМЯ" data-viz-config='{"ключ":значение}'></div>`.
Конфиг — валидный JSON в одинарных кавычках.

| Виджет | Конфиг | Что показывает |
|---|---|---|
| `SetInspector` | `topology`, `initial`, `operator`, `topologySwitch`, `title` | множество на прямой, живые Int/Cl/∂ в трёх топологиях |
| `PointProber` | `set` (`halfPlane`, `practiceFive`, `openDisk`), `startX`, `startY`, `radius` | таскаемая точка, роль точки, влезает ли окрестность |
| `AxiomChecker` | — | серия `(−1/n, 1/n)`, объединение против пересечения, предел |
| `SubspaceViz` | — | NB 1: открытость зависит от объемлющего пространства |
| `TopologyLattice` | `size` (2 или 3) | все топологии на конечном множестве, порядок сильнее/слабее |
| `BlockTopology` | `blocks`, `subset`, `splitBlock` | топология из блоков неразличимых объектов |
| `ArrowTopology` | — | топология стрелки, Int и Cl лучами |

Новый виджет: `register('Имя', (host, config) => { ... })` в `viz.js`, отрисовка через
примитивы `render.js`, перерисовка по событию `host.addEventListener('difgem:redraw', draw)` —
без этого виджет не переживёт переключение темы. Обязательно `touch-action: none` уже стоит
в `.viz__canvas`, но проверь работу на 375px ширине.

## Порядок работы над лекцией

1. Прочитать PDF из `data/lections/`.
2. Скопировать `templates/lecture-template.html` в `conspect/lectures/lecture-NN.html`.
3. Перенести все `Def`/`Lm`/`Th`/`Ex`/`NB` дословно, с нумерацией и `id`.
4. Добавить слои: интуиция к каждому неочевидному определению, ловушки, контрпримеры,
   разбор доказательств по шагам, `ml`-блоки, сводные таблицы, карточки.
5. Подобрать виджеты из каталога; недостающие вычисления — в модули с тестами.
6. Добавить карточку лекции в `index.html` (`data-progress-for="lecture-NN/"`,
   `data-progress-total` — число разделов).
7. `npm test` и `npm run build`.
8. Проверить в браузере: `npm run serve`, затем консоль без ошибок, все виджеты отрисованы,
   формулы отрендерены, оглавление построено.

## Чеклист готовности лекции

- [ ] все формулировки PDF на месте, нумерация совпадает
- [ ] у каждого раздела есть визуал и `ml`-блок
- [ ] доказательства разобраны по шагам с указанием аксиом
- [ ] не меньше четырёх карточек
- [ ] ответы в примерах сверены с `topology.js` там, где вычислимы
- [ ] `npm test` — всё зелёное
- [ ] `npm run build` выполнен, `bundle.js` и индекс обновлены
- [ ] консоль браузера чиста, `.viz__error` не встречается
- [ ] тёмная и светлая темы читаемы, печать не ломается
- [ ] внешних ссылок на ресурсы нет
