# itmo/academic

Учебные материалы. Сейчас в репозитории один курс — дифференциальная геометрия.

## Конспект по дифгему

Локальный офлайн-сайт: `conspect/index.html` — открывается двойным кликом, интернет не нужен.

Конспект преподавателя сохранён дословно и с его нумерацией, а поверх добавлены слои:
интуиция, разбор доказательств по шагам, контрпримеры, ловушки, связи с задачами машинного
обучения, интерактивные виджеты, анимации, карточки самопроверки и автосборная шпаргалка.

```
conspect/
├── index.html          карта курса, глобальный поиск по формулировкам
├── cheatsheet.html     шпаргалка, собирается автоматически
├── lectures/           конспекты лекций
├── pract/              разборы практических листов
├── assets/             topology.js, finite-topology.js, viz.js, render.js, app.js, style.css
├── media/              видео и рендеры анимаций
├── manim/              исходники анимаций (см. manim/README.md)
├── tools/              build.mjs, serve.mjs
└── tests/              юнит-тесты вычислительных модулей
data/                   PDF преподавателя, read-only
```

## Команды

```bash
npm test          # юнит-тесты (41): Int/Cl/граница, перечисление топологий, сборщик индекса
npm run build     # пересобрать bundle.js, поисковый индекс, данные шпаргалки
npm run serve     # http://localhost:4173
```

Зависимостей у сайта нет: тесты идут на встроенном тест-раннере Node, KaTeX вендорен локально.
Страницы подключают собранный `assets/bundle.js`, потому что по `file://` браузер блокирует
ES-модули — поэтому после правки файлов в `assets/*.js` нужен `npm run build`.

Для анимаций отдельное окружение, см. [conspect/manim/README.md](conspect/manim/README.md).

## Как устроены вычисления

Топологические операции вынесены в чистые модули и покрыты тестами, а виджеты — только
отрисовка. Благодаря этому ответы в конспекте не пишутся на глаз: примеры Ex. 8, 10, 11
и ответы к задачам 1, 3, 9, 12, 17\*, 18c практического листа проверяются юнит-тестами.
Числа 4 и 29 (топологий на двух и трёх точках) служат независимой проверкой перечисления.
